# Cultivation — 修炼体系

Status:    Canon
Parent:    Canon/Universe/Universe.md

> 不是境界表。是修炼为什么能变强。
> 所有人都走同一条路，但在路上走出的深度不同。

---

## 修炼七层

```
灵气（外部）
  ↓ 吸收
经脉（通道）
  ↓ 炼化
丹田（容器）
  ↓ 凝聚
灵海（修为）
  ↓ 质变
神魂（本质）
  ↓ 参悟
大道（终极）
  ↓ 超越
飞升（离开）
```

每一层都是下一层的基础。
不能跳过。
不能颠倒。

---

## 第一层：灵气（外部）

```
一切修炼从灵气开始。

灵气 = 三千大道的呼吸（参见 Canon/Universe/Cosmology.md）。

没有灵气 → 无法修炼。
灵气浓度 → 修炼速度。
灵气属性 → 修炼方向（火灵气充足 → 火系修炼更快）。

修士的第一课：感知灵气的存在。
不是"看到"，是"感到"。
就像你感觉不到空气，直到你深呼吸。
修炼就是学会"深呼吸"灵气。
```

---

## 第二层：经脉（通道）

```
经脉 = 灵气进入身体的通道。

全身有 108 条主要经脉。
最初大部分是堵塞的。

练气期的本质：
  打通经脉。
  每打通一条经脉 → 灵气流通多一分。
  打通全部 108 条经脉 → 练气圆满 → 可以筑基。

经脉打通 = 不可逆。
一旦打通，不会再堵塞。
但经脉可以被破坏（重伤、走火入魔）。
破坏的经脉可以修复，但极其困难。

经脉质量 = 修炼速度的上限。
  经脉越宽 → 灵气流速越快。
  经脉越韧 → 承受的灵气量越大。

功法影响经脉：
  好功法 → 打通的经脉更多、更宽。
  差功法 → 可能只打通 72 条就"圆满"了。
  这就是功法的本质区别。
```

---

## 第三层：丹田（容器）

```
丹田 = 灵气的容器。位于脐下三寸。

凡人也有丹田，但丹田是"干涸的"。
修炼的第一步 → 让灵气流入丹田。

丹田有三个阶段：

  气态丹田（练气期）
    灵气在丹田中如雾气。
    量少、不稳定、威力低。

  液态丹田（筑基期）
    灵气压缩为液体。
    储存量暴增（约 10 倍）。
    这是筑基的本质——不是"变强了"，是"容器升级了"。

  固态丹田（金丹期）
    液态灵气凝聚为金丹。
    一颗金丹 = 全部修为的结晶。
    金丹不坏 → 灵魂有依托。
    金丹碎裂 → 修为全失（极其危险）。

筑基的本质：
  本质不是"第二境界"。
  本质是丹田从气态变成液态。
  境界名称只是这个物理过程的标签。
```

---

## 第四层：灵海（修为）

```
灵海 = 灵气的海洋。修士的全部修为。

金丹期之后，丹田不再是唯一容器。
灵海在丹田之外展开——遍布全身。

灵海的大小 = 你的修为量。

  金丹期：灵海初开，约 1 丈。
  元婴期：灵海扩展，约 10 丈。
  化神期：灵海与神魂融合，约 100 丈。
  渡劫期：灵海近乎无穷（但仍有限）。
  大乘期：灵海与天地共鸣——你呼吸，天地呼吸。

灵海满了 → 才能突破。
灵海不满 → 无法突破。

修炼的本质 = 往灵海里装灵气。
突破的本质 = 换一个更大的灵海。
```

---

## 第五层：神魂（本质）

```
神魂 = 灵魂 + 神识。你的本质。

元婴之上，修炼不再只是"装灵气"。
而是"强化神魂"。

元婴的形成：
  金丹碎裂 → 灵魂与灵力结合 → 元婴诞生。
  元婴 = 你的第二生命。
  元婴可以脱离肉体（肉体被毁时可以逃脱）。

化神的本质：
  神魂开始与灵海融合。
  你不再"拥有"灵力。
  你就是灵力。

渡劫的本质：
  神魂承受天劫的淬炼。
  每一次天劫 → 神魂更纯粹 → 更接近大道。
  天劫不是惩罚，是淬炼。
  但淬炼可能杀死你。
```

---

## 第六层：大道（终极）

```
大道的参悟。参见 Canon/Dao/Dao.md。

修炼的最高层次不是"灵力无限"。
修炼的最高层次是"理解大道"。

大乘期的本质：
  你已经不只是在修炼灵力。
  你在参悟本源大道。
  每参悟一条本源大道 → 你离飞升更近一步。

参悟全部五条本源大道（时间、空间、命运、因果、轮回）
→ 圆满 → 可以飞升。

但：
  每条本源大道需要至少千年参悟。
  大乘期寿元一万年。
  你只有一万年。
  五条大道 = 至少五千年。
  时间够吗？够。但你能活到那时候吗？

  这就是为什么飞升者凤毛麟角。
  不是实力不够。
  是时间不够。
```

---

## 第七层：飞升（离开）

```
飞升 = 离开凡间，进入仙界。

条件：
  - 大乘期圆满
  - 参悟全部五条本源大道
  - 渡过飞升天劫

飞升不是"变强"。
飞升是"换一个世界"。

飞升之后：
  - 不再受凡间规则约束。
  - 仙界的修炼体系与凡间不同。
  - 不可返回凡间（飞升通道几乎断绝）。

当前末法时代：
  - 飞升通道几乎完全断绝。
  - 近万年来飞升者不足十人。
  - 大乘期修士被困在凡间，寿元耗尽而死。
  - 这是最大的绝望。
```

## 修炼与境界的关系

```
境界 ≠ 修炼层次。
境界 = 修炼层次的对外表现。

  练气 → 经脉打通
  筑基 → 丹田液化
  金丹 → 丹田固化
  元婴 → 神魂具象
  化神 → 神魂与灵海融合
  渡劫 → 神魂淬炼
  大乘 → 大道参悟
  飞升 → 离开凡间

境界是现象。修炼是本质。

AI 必须理解本质，而不仅仅是境界名称。
```

---

## 不可变

1. 修炼七层顺序不可变。
2. 经脉总数 108 条不可变。
3. 丹田三态（气→液→固）不可变。
4. 飞升需要参悟全部五条本源大道。
5. 飞升后不可返回凡间。

## AI 须知

```
描述修炼过程时：
  ✅ 必须体现七层递进
  ✅ 境界名称是标签，修炼本质是内容
  ❌ 不能说"他一下子突破了三层"

设计 NPC 时：
  ✅ NPC 的修炼进度体现在七层中
  ✅ "筑基失败" = "丹田无法液化"
  ❌ 不能出现"他练气期就参悟了本源大道"

设计功法时：
  ✅ 功法影响经脉打通效率
  ✅ 功法影响丹田转化速度
  ❌ 功法不能跳过某一层
```
