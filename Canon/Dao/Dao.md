# Dao — 大道

Status:    Canon
Parent:    Canon/Universe/Universe.md

> 不是金木水火土。
> 不是技能树。
> 大道是三层体系。

---

## 三层大道

```
Origin Dao（本源大道）
  宇宙存在的基础法则
  不可创造、不可毁灭
  所有修士的终极追求
    │
    ▼
Natural Dao（自然大道）
  物质世界的构成元素
  天地自然产生
  法术的力量来源
    │
    ▼
Human Dao（人道）
  人类文明的技术结晶
  由修士创造和传承
  技巧的核心
```

---

## Origin Dao（本源大道）

```
本源大道 = 宇宙为什么存在的答案。

数量：5 条（不可增减）

  时间之道    — 一切流动的原因
  空间之道    — 一切位置的原因
  命运之道    — 一切轨迹的原因
  因果之道    — 一切联系的原因
  轮回之道    — 一切循环的原因

参悟要求：
  至少元婴期才能开始参悟。
  每条本源大道需要千年以上的参悟时间。
  完全参悟一条本源大道 = 大乘期的核心条件。

获取方式：
  不是"学会"。
  是"领悟"。
  无法传授。无法抄录。只能自己悟。

战力影响：
  不是直接战斗力。
  参悟本源大道 = 你对世界本质的理解加深。
  这种理解影响一切。
  你的技能威力因此提升。
  你的突破因此更容易。
  但本源大道本身不产生火球。
```

---

## Natural Dao（自然大道）

```
自然大道 = 物质世界由什么构成。

数量：8 条（不可增减）

  金之大道    — 金属、锋锐、杀伐
  木之大道    — 生命、生长、恢复
  水之大道    — 流动、适应、侵蚀
  火之大道    — 燃烧、毁灭、激情
  土之大道    — 稳固、防御、厚重
  风之大道    — 速度、自由、无形
  雷之大道    — 毁灭、审判、极速
  冰之大道    — 静止、保存、纯粹（水之大道的分支）

参悟要求：
  筑基期可以开始参悟。
  与灵根相关——有火灵根的人参悟火之大道更快。
  但灵根不限制参悟——没有火灵根也能参悟火之大道，只是更慢。

获取方式：
  修炼 + 实践。
  使用对应属性的功法会加速参悟。
  在对应属性的环境中修炼更快（火山口→火之大道）。

战力影响：
  直接战斗力。
  火之大道 → 火焰法术威力。
  金之大道 → 武器伤害。
  参悟越深 → 对应属性的技能越强。

五行相生相克：
  金 → 水 → 木 → 火 → 土 → 金（相生）
  金 → 木 → 土 → 水 → 火 → 金（相克）
  但这是自然规律，不是游戏设定。
  水能克火，但洪水灭不了太阳。
  大道有层级，不是死板的克制表。
```

## Human Dao（人道）

```
人道 = 人类文明创造的大道。

数量：不固定。随文明发展而增减。

  剑道    — 剑术的极致
  丹道    — 炼丹的极致
  阵道    — 阵法的极致
  符道    — 符箓的极致
  器道    — 炼器的极致
  体道    — 炼体的极致
  魂道    — 灵魂的极致
  杀道    — 杀戮的极致
  情道    — 情感的极致
  ……    — 人类尚有未开创的大道

特点：
  人道不是自然存在的。
  人道是被创造出来的。

  第一个拿起剑的人，创造了剑道的雏形。
  第一个炼出丹药的人，创造了丹道的雏形。
  经过万年传承、改良、升华，
  这些人造的技术达到了"近乎大道"的高度。

  人道可以被创新。
  未来可能出现新的人道。
  但需要合理性——不是"我突然创造了炸鸡道"。

参悟要求：
  练气期可以开始参悟。
  主要通过实践和学习。
  有师父引导 → 快。
  自己摸索 → 慢但可能独创。

获取方式：
  学习 + 修炼 + 实践。
  可以被传授。可以被抄录。
  宗门可以专攻某一条人道。

战力影响：
  直接战斗力。
  剑道 → 一切剑类技能。
  丹道 → 炼丹成功率 + 丹药效果。
  阵道 → 阵法威力。
```

## 大道之间的关系

```
参悟多条大道 = 可能的。

但：
  时间有限。
  寿元有限。
  你不可能参悟所有大道。

  专精一条 → 极深 → 极强。
  广涉多条 → 各浅 → 样样通样样松。

修士的选择：
  大多数修士：1 条 Human Dao + 1 条 Natural Dao。
  天才：1 Human + 1 Natural + 1 Origin。
  传说：多条 Origin（但谁会活那么久？）

技能与大道的关系：
  每个技能必须声明借用了哪条大道。
  可以借用多条大道（如：剑道 + 火之大道 = 焚天剑诀）。
  大道组合没有限制——但借用越多，参悟要求越高。
```

---

## 不可变

1. Origin Dao 5 条不可增减。
2. Natural Dao 8 条不可增减。
3. Human Dao 可以新增（需 ADR）。
4. 大道之间的层级关系不可变（Origin > Natural > Human）。
5. 任何技能必须归属于至少一条大道。

## AI 须知

```
生成技能时：
  ✅ 必须声明技能归属于哪条大道
  ✅ 可以归属于多条大道
  ❌ 不能创造新的大道（除非 Human Dao 且经 ADR）

生成 NPC 时：
  ✅ NPC 可以"擅长某条大道"
  ❌ NPC 不能"掌控某条大道"（掌控 = 成神）

生成宗门时：
  ✅ 宗门可以专攻特定大道的组合
  ✅ 同一大道可以被多个宗门参悟

永恒规则：
  大道高于仙帝。
  没有人可以凌驾于大道之上。
```
