# Time Engine — 时间引擎

Status:    Canon
Parent:    Canon/Universe/Universe.md

> 世界不静止。
> 即使玩家什么都没做，世界照样变化。

---

## 时间映射

```
现实时间 → 游戏时间

  1 秒   = 1 游戏时辰（2 小时）
  6 秒   = 1 游戏日（12 时辰）
  3 分钟 = 1 游戏月（30 日）
  36 分钟 = 1 游戏年（12 月）

换算：
  现实 1 小时 = 游戏 100 天 ≈ 1/3 年
  现实 1 天   = 游戏 2400 天 ≈ 6.5 年
  现实 1 周   = 游戏 ≈ 46 年

玩家离线一周回来后：
  世界已经过去了 46 年。
  NPC 可能已经突破、死亡、结婚、生了孩子。
  宗门可能已经换了两任掌门。
  这不是背景更新，这是真实的时间流逝。
```

---

## Daily Tick（每日推进）

```
每个游戏日（现实 6 秒），以下流程自动执行：

  ① NPC 修炼
     所有 NPC 自动修炼一日。
     修为增长 = 灵根系数 × 灵气浓度 × 功法系数 × 1 日。

  ② 突破检查
     灵海已满的 NPC 尝试突破。
     成功率计算 → 随机判定。
     成功 → 境界提升，世界公告（如有重大突破）。
     失败 → 修为倒退，可能受伤。

  ③ 经济运转
     市场价格波动（供需模拟）。
     NPC 之间交易。
     NPC 资金变化。

  ④ 宗门事务
     宗门内部管理（弟子晋升、任务分配）。
     宗门之间外交（关系变化、联盟/敌对）。
     可能触发宗门战争。

  ⑤ 生命事件
     年龄 +1 日（每年 NPC 年龄 +1 岁）。
     寿元检查 → 耗尽 → 死亡。
     NPC 可能结婚、生子。
     NPC 可能走火入魔、意外死亡。

  ⑥ 世界事件
     天气变化。
     灵气浓度波动。
     秘境开启/关闭。
     特殊事件触发（随机）。

  ⑦ 历史记录
     重要事件写入 Memory。
     普通事件丢弃。
```

## 玩家在线 vs 离线

```
玩家在线：
  世界时间正常推进。
  玩家可以看到 NPC 的行动。
  玩家可以干预事件。

玩家离线：
  世界时间继续推进。
  流程照常执行。
  玩家上线 → 收到"离线期间世界发生了什么"的摘要。

离线摘要示例：

  你离开了 7 天（游戏时间 46 年）。

  期间：
  - 青云宗宗主云清真人突破到化神后期。
  - 魔渊与血煞门爆发战争，魔渊战败。
  - 你认识的散修张三寿元耗尽，去世了。
  - 筑基丹价格从 500 涨到 800 灵石。
  - 青云山南麓新发现一条中品灵脉。
  - 你的修为自动修炼增长了一小截。

  世界变了。
```

## 玩家时间控制

```
玩家可以：

  闭关修炼（加速）
    玩家主动选择闭关。
    跳过 N 天的游戏时间。
    N 天后出关。
    期间世界照常运转。

  等待
    正常速度等待。
    可以看到 NPC 实时行动。

  下线
    离开游戏。
    时间仍在推进。
```

## 事件优先级

```
每日推进中，事件有优先级：

  1. 生存事件（最高）
     NPC 是否死亡？
     宗门是否灭亡？
     灵脉是否枯竭？

  2. 修炼事件
     是否突破？
     是否走火入魔？

  3. 关系事件
     宗门战争？
     NPC 结婚？
     盟友背叛？

  4. 经济事件
     价格波动。
     交易发生。

  5. 随机事件
     天气变化。
     奇遇触发。

高优先级事件可能打断低优先级事件。
宗门灭亡 → 以下所有事件无效。
```

## 世界年表

```
游戏时间有记录：

  第 1 年    玩家进入世界。
  第 10 年   第一批 NPC 开始突破。
  第 50 年   宗门格局开始变化。
  第 100 年  第一批 NPC 自然死亡。
  第 500 年  世界可能与玩家初入时完全不同。
  第 1000 年 玩家如果还在，已经见证了数代人的生灭。

时间引擎让"千年修仙"成为真实的体验。
不是"我说我修炼了千年"。
是真的过了一千年。
```

## 实现约束

```
时间引擎必须：

  ✅ 在游戏服务器（或本地）持续运行。
  ✅ 即使没有玩家在线。
  ✅ 每日推进不可跳过。
  ✅ 所有事件可追溯（日志记录）。

不允许：

  ❌ 玩家离线时间暂停。
  ❌ "跳过"某天的推进以节省计算。
  ❌ 事件结果不记录（必须写入 Memory）。
```

---

## 不可变

1. 时间映射比例不可变（1 秒 = 1 游戏时辰）。
2. Daily Tick 流程不可跳过。
3. 玩家离线时间必须继续推进。
4. 重要事件必须写入 Memory。

## AI 须知

```
Simulation 执行时：
  ✅ 必须按 Daily Tick 流程逐项执行
  ✅ 必须记录重要事件
  ✅ 玩家上线必须生成离线摘要
  ❌ 不能跳过步骤
  ❌ 不能"批量处理 1000 天"（必须逐日模拟）

生成 NPC 时：
  ✅ NPC 必须有时钟驱动的行为
  ❌ NPC 不能"等待玩家触发"
```
