# Constants

Status:    Canon
Parent:    Canon/Universe/Universe.md

> 以下规则不可变。
> 不是"最好不要违反"。
> 是"不可违反"。

---

## Constant 001 — 时间不可逆

```
时间只能向前。

不可倒流。
不可暂停（局部操控除外）。
不可跳过。

过去不可改变。
已经发生的事 = 已经发生。

例外：
  仙界时间流速与凡间不同（1日 = 凡间1年）。
  神界时间不流动（永恒）。
  但这些是时间流速的差异，不是逆转。
```

---

## Constant 002 — 死亡真实存在

```
死亡不是"Game Over"。

死亡 = 灵魂离开肉体。
死亡是真实的，不可撤销的。

死后有七条路径（参见 Canon/Death）：
  轮回、鬼魂、鬼修、夺舍、元婴逃脱、魂飞魄散、复活。

但：
  复活不是免费的。复活不是常态。
  魂飞魄散 = 永远消失。

不存在"死了但马上复活继续打"。
不存在"重要 NPC 死了靠丹药救活"（复活丹药极其稀有，非商品）。
```

---

## Constant 003 — 灵气有限

```
灵气不是取之不尽的资源。

九天界的灵气总量是有限的。

灵气可以被消耗。
灵脉可以被耗尽。
灵气浓度影响一切修炼行为。

灵气正在不可逆地稀薄（末法时代）。

不存在"无限灵气挂机"。
不存在"灵气用完了明天自动补满"。
如果你在一个地方过度修炼 → 灵气下降 → 影响所有人。
```

---

## Constant 004 — 突破必然有失败概率

```
突破永远不是 100% 保证的。

每一次突破都有失败的可能。
每一次失败都有代价。

基础成功率从 80%（练气→筑基）到 1%（渡劫→大乘）。
丹药、灵气、机缘、悟性可以提高成功率。
但永远达不到 100%。

不存在"保底突破"。
不存在"必定成功"。
不存在"剧情需要强行突破"。

如果 Canon 规则下无法突破 → 就是无法突破。
找丹药、找机缘、找更好的灵脉。
但不要找 Canon 的例外。
```

## Constant 005 — 一切生命都有寿元

```
没有任何生命可以永远活着。

凡人 60-80 年。
练气 120 年。
筑基 250 年。
金丹 500 年。
元婴 1000 年。
化神 2000 年。
渡劫 5000 年。
大乘 10000 年。

大乘之后可以飞升（进入仙界，不在凡间寿元体系内）。

延寿丹药最多延长 30%。
同一丹药只生效一次。

不存在"活了十万年的金丹修士"。
不存在"不死之身"。

即使是仙帝，在凡间也只能活一万年。
（仙帝在仙界的寿元规则不在当前 Canon 范围内）
```

## Constant 006 — 没有绝对无敌

```
没有任何存在是绝对无敌的。

每一次战斗都有不确定性。
每一次对抗都有弱点可以被利用。

最强的修士可能被：
  - 更巧妙的战术击败
  - 天劫摧毁
  - 寿元耗尽
  - 心魔吞噬
  - 因果反噬

不存在"无敌属性"。
不存在"绝对防御"。
不存在"秒杀一切"。

大道本身都没有"绝对"。
大道只是更高的规则。
规则之上还有混沌。
混沌之上……不可知。
```

## 修改协议

任何 Constant 的修改需要：

1. Architect 提案
2. ADR 记录
3. 影响评估（所有引用此常数的系统）
4. 更新本文档版本号
5. 通知所有 AI

Constant 001-006 不可修改。
常数的数值可以根据平衡调整（需 ADR）。
但常数的存在本身不可删除。
