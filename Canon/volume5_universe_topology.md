## 六层完整架构

```
大道 → 天道 → Universe Engine → World Engine → Simulation → NPC/玩家
```

Universe Engine 位于 World Engine 之上，负责跨域协调。六个子系统：Realm、Barrier、Ascension、Reincarnation、Karma、Void。

每个界（凡界/灵界/仙界/魔界/冥界/虚空）是独立的 World Engine 实例，拥有独立的时间流速、灵气规则、修炼上限。

新增界域：Registry 注册 → 实例化 World Engine → 配置界壁 → 已有代码零改动。

---

## 六界

凡界、灵界、仙界、魔界、冥界、虚空。不是上下关系，而是不同规则的世界。

| 界 | 特点 | 修炼上限 |
|----|------|----------|
| 凡界 | 灵气稀薄，文明最多 | 渡劫 |
| 灵界 | 灵气浓郁，远古遗迹 | 仙王 |
| 仙界 | 灵气液化，仙族所在 | 仙帝 |
| 魔界 | 魔气充盈，竞争极端 | 仙帝 |
| 冥界 | 灵魂归宿，轮回管理 | - |
| 虚空 | 无灵气无时间，界兽 | - |

魔界不是邪恶世界。是另一种修炼文明。同样遵守因果。

冥界不是地狱。是生命循环管理器：因果审查 → 轮回安排。

---

## 宇宙层级

大道 → 天道 → 六界 → 小世界 → 秘境 → 洞天 → 个人空间

---

## 世界屏障

六界之间由界壁隔离。作用：维持规则稳定、限制力量外溢、保护低层世界。

跨越方式：飞升、界门、空间神通、世界裂缝、特殊法宝。

---

## 飞升

不是奖励，是世界迁移。条件：达到上限 → 通过天劫 → 获得认可 → 穿越界壁 → 进入更高世界。失败可能：死亡、停留原界、坠入虚空。

飞升不会删除过去的因果。

---

## 跨界影响

仙界大战 → 大道震荡 → 灵界灵气变化 → 凡界灵潮爆发。魔界入侵 → 界壁受损 → 凡界出现魔域。冥界异常 → 轮回停滞 → 怨魂出现。世界之间存在因果联系。
