## 物品见证的事件

```
1. 九天魔尊之战 (天历前 200 年) — imp=10
2. 南天门镇守 (天历 150~500 年) — imp=8
3. 仙魔大战·李云陨落 (天历 500 年) — imp=10
4. 东海沉睡四百年 (天历 500~820 年) — imp=6
5. 剑灵被唤醒 (天历 820 年) — imp=8
6. 剑阁建立 (天历 830 年) — imp=7
7. 剑阁覆灭 (天历 847 年) — imp=9

总计: 7 个重大事件，跨越 1197 年
```

## 叙事视角

```
从 NPC 视角:
  "陈玄听说过斩仙剑。传说它在东海某处沉睡着。"
  → 一件传说中的法宝。

从法宝视角:
  "斩仙剑在海底沉睡四百年后，被王辰的鲜血唤醒。
   它记得九天魔尊的血。记得李云陨落时的哀鸣。
   记得每一个主人的手温。"
  → 一段沉默的历史。
```

# 青云宗 — 400 年

## 宗门大事记

```
天历 500 年 — 青云真人创立青云宗
  imp=10 | founding
  青云真人于青云峰开山立派，传下青云心法。

天历 520 年 — 青云真人飞升
  imp=10 | leader_transition
  在登仙台飞升仙界。青云宗进入长老共治时代。

天历 600 年 — 第一次正邪大战
  imp=9 | crisis
  魔渊大举进攻，青云宗死伤过半。战后重建。

天历 700 年 — 发现青云主脉
  imp=9 | golden_age_start
  在青云峰深处发现天级灵脉。宗门进入三百年黄金时代。

天历 750 年 — 青云书院建立
  imp=7 | institution
  建立青云书院，系统培养弟子。制度化的开端。

天历 827 年 — 陈玄被逐
  imp=8 | internal_conflict
  大长老公孙烈诬陷陈玄"勾结魔道"，将其逐出师门。
  李长风沉默。这件事二十年后仍影响着青云宗的命运。

天历 835 年 — 大长老一系掌权
  imp=7 | power_shift
  公孙烈架空改革派，青云宗进入"颜面优先"时代。

天历 844 年 — 林远被杀事件
  imp=9 | crisis_moral
  外门弟子王虎杀害散修林远。宗门以"私人恩怨"为由拒绝交人。

天历 847 年 — 灵脉枯竭危机
  imp=10 | crisis_existential
  青云主脉灵气从 150 降至 60。宗门面临史上最大危机。
```

## 宗门记忆 vs NPC 记忆

```
青云宗记忆（组织层面）:
  "天历 827 年，弟子陈玄因'勾结魔道'被逐出师门。"
  → 冷冰冰的官方记录。

陈玄记忆（个人层面）:
  "那天大雨。大长老诬陷我，师父一言不发。"
  → 刻骨的私人记忆。

李长风记忆（个人层面）:
  "我本可以站出来。我没有。那一眼我记了二十年。"
  → 沉默的愧疚。

同一个事件，三层记忆。
组织记忆不关心感受。个人记忆充满了感受。
但两者都必须存在——这才是一个完整的世界。
```
